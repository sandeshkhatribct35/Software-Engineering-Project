# FairShare API Reference

Base URL (local): `http://localhost:8000`
All resource endpoints are under `/api/v1`. The health endpoint sits at the root.

Interactive versions of this document are generated by the application itself:

| Format | URL |
|---|---|
| Swagger UI (try requests in the browser) | `http://localhost:8000/docs` |
| ReDoc (reference layout) | `http://localhost:8000/redoc` |
| OpenAPI schema (machine readable) | `http://localhost:8000/openapi.json` |

A committed snapshot of the schema is kept at [`openapi.json`](openapi.json) and is
regenerated with `python scripts/export_openapi.py`.

---

## Conventions

- Requests and responses are JSON.
- **Monetary amounts are strings with exactly two decimals** (`"333.34"`). JSON
  numbers are binary floating point and cannot represent money exactly, so the
  API never sends money as a number.
- Timestamps are ISO-8601 in UTC.
- `201` is returned for creations, `204` for deletions, `200` for reads and updates.

## Error format

Every failing request returns the same shape:

```json
{ "detail": "Group 7 does not exist", "code": "GROUP_NOT_FOUND" }
```

`detail` is for humans; `code` is stable and safe for a client to branch on.

| Status | Meaning | Codes |
|---|---|---|
| 404 | The resource does not exist | `GROUP_NOT_FOUND`, `MEMBER_NOT_FOUND`, `EXPENSE_NOT_FOUND`, `NOT_FOUND` |
| 409 | Conflicts with the current state | `DUPLICATE_MEMBER_NAME`, `MEMBER_HAS_ACTIVITY` |
| 422 | Fails a domain rule | `PAYER_NOT_IN_GROUP`, `PARTICIPANT_NOT_IN_GROUP`, `DUPLICATE_PARTICIPANT`, `NO_PARTICIPANTS`, `SHARES_DO_NOT_SUM`, `NEGATIVE_SHARE`, `SAME_MEMBER_SETTLEMENT`, `MEMBER_NOT_IN_GROUP` |
| 422 | Fails schema validation (type, length, bounds) | `VALIDATION_ERROR` |
| 405 | Method not allowed on that path | `METHOD_NOT_ALLOWED` |
| 500 | Unexpected server fault (details are logged, never returned) | `INTERNAL_ERROR` |

# Groups

## `POST /api/v1/groups` — create a group

| Field | Type | Required | Rules |
|---|---|---|---|
| `name` | string | yes | 1–100 chars, not blank (trimmed) |
| `description` | string \| null | no | max 500 chars |
| `currency` | string | no | exactly 3 uppercase letters, default `NPR` |

```bash
curl -X POST http://localhost:8000/api/v1/groups \
  -H 'Content-Type: application/json' \
  -d '{"name":"Pokhara Trip","description":"Weekend trip","currency":"NPR"}'
```

`201 Created`
```json
{
  "id": 1,
  "name": "Pokhara Trip",
  "description": "Weekend trip",
  "currency": "NPR",
  "created_at": "2026-08-15T18:38:06.455112Z"
}
```

Errors: `422 VALIDATION_ERROR`.

## `GET /api/v1/groups` — list groups

Newest first.

```bash
curl http://localhost:8000/api/v1/groups
```

`200 OK` — array of group objects.

## `GET /api/v1/groups/{group_id}` — group detail

Includes the member list.

```bash
curl http://localhost:8000/api/v1/groups/1
```

`200 OK`
```json
{
  "id": 1,
  "name": "Pokhara Trip",
  "description": "Weekend trip",
  "currency": "NPR",
  "created_at": "2026-08-15T18:38:06.455112Z",
  "members": [
    { "id": 1, "group_id": 1, "name": "Sandesh", "created_at": "2026-08-15T18:38:07.101Z" }
  ]
}
```

Errors: `404 GROUP_NOT_FOUND`.

## `PATCH /api/v1/groups/{group_id}` — update a group

Only `name` and `description` may be changed. Fields left out are unchanged.

```bash
curl -X PATCH http://localhost:8000/api/v1/groups/1 \
  -H 'Content-Type: application/json' \
  -d '{"name":"Pokhara Trip 2026"}'
```

`200 OK` — the updated group. Errors: `404 GROUP_NOT_FOUND`, `422 VALIDATION_ERROR`.

## `DELETE /api/v1/groups/{group_id}` — delete a group

Deletes the group and every member, expense, share and settlement inside it.

```bash
curl -X DELETE http://localhost:8000/api/v1/groups/1
```

`204 No Content`. Errors: `404 GROUP_NOT_FOUND`.

# Members

## `POST /api/v1/groups/{group_id}/members` — add a member

| Field | Type | Required | Rules |
|---|---|---|---|
| `name` | string | yes | 1–80 chars, not blank, unique within the group (case-insensitive) |

```bash
curl -X POST http://localhost:8000/api/v1/groups/1/members \
  -H 'Content-Type: application/json' \
  -d '{"name":"Sandesh"}'
```

`201 Created`
```json
{ "id": 1, "group_id": 1, "name": "Sandesh", "created_at": "2026-08-15T18:38:07.101Z" }
```

Errors: `404 GROUP_NOT_FOUND`, `409 DUPLICATE_MEMBER_NAME`, `422 VALIDATION_ERROR`.

## `GET /api/v1/groups/{group_id}/members` — list members

In the order they were added. Errors: `404 GROUP_NOT_FOUND`.

## `DELETE /api/v1/groups/{group_id}/members/{member_id}` — remove a member

Allowed only when the member has paid no expense, shares no expense and takes
part in no settlement — removing them otherwise would change everyone's balance.

```bash
curl -X DELETE http://localhost:8000/api/v1/groups/1/members/3
```

`204 No Content`. Errors: `404 GROUP_NOT_FOUND`, `404 MEMBER_NOT_FOUND`, `409 MEMBER_HAS_ACTIVITY`.

# Expenses

## `POST /api/v1/groups/{group_id}/expenses` — record an expense

| Field | Type | Required | Rules |
|---|---|---|---|
| `description` | string | yes | 1–200 chars, not blank |
| `amount` | string/number | yes | > 0, ≤ 1000000.00, at most 2 decimals |
| `paid_by_id` | integer | yes | must be a member of the group |
| `split_type` | `EQUAL` \| `EXACT` | yes | |
| `participant_ids` | array of integer | only for `EQUAL` | non-empty, no repeats, all in the group |
| `shares` | array of `{member_id, share_amount}` | only for `EXACT` | non-empty, no repeats, all in the group, must sum to `amount` |

Supplying `shares` with `EQUAL` (or `participant_ids` with `EXACT`) is rejected.

**Equal split** — the amount is divided in paisa and the indivisible remainder
goes to the lowest member ids, so the shares always add up exactly:

```bash
curl -X POST http://localhost:8000/api/v1/groups/1/expenses \
  -H 'Content-Type: application/json' \
  -d '{
        "description":"Hotel in Pokhara",
        "amount":"1000.00",
        "paid_by_id":1,
        "split_type":"EQUAL",
        "participant_ids":[1,2,3]
      }'
```

`201 Created`
```json
{
  "id": 1,
  "group_id": 1,
  "description": "Hotel in Pokhara",
  "amount": "1000.00",
  "paid_by_id": 1,
  "paid_by_name": "Sandesh",
  "split_type": "EQUAL",
  "created_at": "2026-08-15T18:38:10.220Z",
  "shares": [
    { "member_id": 1, "member_name": "Sandesh", "share_amount": "333.34" },
    { "member_id": 2, "member_name": "Bikash",  "share_amount": "333.33" },
    { "member_id": 3, "member_name": "Anita",   "share_amount": "333.33" }
  ]
}
```

**Exact split**:

```bash
curl -X POST http://localhost:8000/api/v1/groups/1/expenses \
  -H 'Content-Type: application/json' \
  -d '{
        "description":"Dinner",
        "amount":"1200.00",
        "paid_by_id":2,
        "split_type":"EXACT",
        "shares":[
          {"member_id":1,"share_amount":"500.00"},
          {"member_id":2,"share_amount":"700.00"}
        ]
      }'
```

Errors: `404 GROUP_NOT_FOUND`, `422 PAYER_NOT_IN_GROUP`, `422 PARTICIPANT_NOT_IN_GROUP`,
`422 DUPLICATE_PARTICIPANT`, `422 NO_PARTICIPANTS`, `422 SHARES_DO_NOT_SUM`,
`422 NEGATIVE_SHARE`, `422 VALIDATION_ERROR`.

## `GET /api/v1/groups/{group_id}/expenses` — list expenses

| Query | Type | Default | Rules |
|---|---|---|---|
| `limit` | integer | 50 | 1–100 |
| `offset` | integer | 0 | ≥ 0 |

```bash
curl 'http://localhost:8000/api/v1/groups/1/expenses?limit=10&offset=0'
```

`200 OK` — array of expense objects, newest first.
Errors: `404 GROUP_NOT_FOUND`, `422 VALIDATION_ERROR`.

## `GET /api/v1/expenses/{expense_id}` — expense detail

`200 OK` — one expense with its shares. Errors: `404 EXPENSE_NOT_FOUND`.

## `DELETE /api/v1/expenses/{expense_id}` — delete an expense

Removes the expense and its shares; balances change immediately.

`204 No Content`. Errors: `404 EXPENSE_NOT_FOUND`.

# Balances and settlement

## `GET /api/v1/groups/{group_id}/balances` — net balances

`balance = paid − owed + settlements paid − settlements received`.
Positive means the group owes the member. **The balances always sum to `0.00`.**

```bash
curl http://localhost:8000/api/v1/groups/1/balances
```

`200 OK`
```json
{
  "group_id": 1,
  "currency": "NPR",
  "balances": [
    { "member_id": 1, "member_name": "Sandesh", "balance": "666.66" },
    { "member_id": 2, "member_name": "Bikash",  "balance": "-333.33" },
    { "member_id": 3, "member_name": "Anita",   "balance": "-333.33" }
  ]
}
```

Errors: `404 GROUP_NOT_FOUND`.

## `GET /api/v1/groups/{group_id}/settlement-plan` — who should pay whom

The largest debtor is matched with the largest creditor until every balance is
zero. A group of *n* members never needs more than *n − 1* payments, and a
settled group returns an empty plan.

```bash
curl http://localhost:8000/api/v1/groups/1/settlement-plan
```

`200 OK`
```json
{
  "group_id": 1,
  "currency": "NPR",
  "transfers": [
    {
      "from_member_id": 2, "from_member_name": "Bikash",
      "to_member_id": 1,   "to_member_name": "Sandesh",
      "amount": "333.33"
    },
    {
      "from_member_id": 3, "from_member_name": "Anita",
      "to_member_id": 1,   "to_member_name": "Sandesh",
      "amount": "333.33"
    }
  ],
  "transfer_count": 2
}
```

Errors: `404 GROUP_NOT_FOUND`.

## `POST /api/v1/groups/{group_id}/settlements` — record a payment

| Field | Type | Required | Rules |
|---|---|---|---|
| `from_member_id` | integer | yes | member of the group, different from `to_member_id` |
| `to_member_id` | integer | yes | member of the group |
| `amount` | string/number | yes | > 0, at most 2 decimals |
| `note` | string \| null | no | max 200 chars |

```bash
curl -X POST http://localhost:8000/api/v1/groups/1/settlements \
  -H 'Content-Type: application/json' \
  -d '{"from_member_id":3,"to_member_id":1,"amount":"333.33","note":"Paid by eSewa"}'
```

`201 Created`
```json
{
  "id": 1,
  "group_id": 1,
  "from_member_id": 3,
  "to_member_id": 1,
  "amount": "333.33",
  "note": "Paid by eSewa",
  "settled_at": "2026-08-15T18:39:02.884Z"
}
```

Errors: `404 GROUP_NOT_FOUND`, `422 SAME_MEMBER_SETTLEMENT`, `422 MEMBER_NOT_IN_GROUP`,
`422 VALIDATION_ERROR`.

## `GET /api/v1/groups/{group_id}/settlements` — list payments

`200 OK` — newest first. Errors: `404 GROUP_NOT_FOUND`.

## A complete worked example

```bash
# 1. Create a group and add three people
GROUP=$(curl -s -X POST http://localhost:8000/api/v1/groups \
  -H 'Content-Type: application/json' -d '{"name":"Pokhara Trip"}' | jq -r .id)

for NAME in Sandesh Bikash Anita; do
  curl -s -X POST http://localhost:8000/api/v1/groups/$GROUP/members \
    -H 'Content-Type: application/json' -d "{\"name\":\"$NAME\"}"
done

# 2. Sandesh pays 1000 for the hotel, split equally
curl -s -X POST http://localhost:8000/api/v1/groups/$GROUP/expenses \
  -H 'Content-Type: application/json' \
  -d '{"description":"Hotel","amount":"1000.00","paid_by_id":1,
       "split_type":"EQUAL","participant_ids":[1,2,3]}'

# 3. See who owes what, and the payments that settle it
curl -s http://localhost:8000/api/v1/groups/$GROUP/balances
curl -s http://localhost:8000/api/v1/groups/$GROUP/settlement-plan

# 4. Record one of those payments
curl -s -X POST http://localhost:8000/api/v1/groups/$GROUP/settlements \
  -H 'Content-Type: application/json' \
  -d '{"from_member_id":3,"to_member_id":1,"amount":"333.33"}'

# 5. Anita is now settled
curl -s http://localhost:8000/api/v1/groups/$GROUP/balances
```
